# API Connect — Android Networking Demo

A Java/XML Android app demonstrating Retrofit GET, Volley GET, Volley POST, and JSON response parsing with a redesigned interface.

## Build
Run `gradle --no-daemon assembleDebug` from this directory.

APK output: `app/build/outputs/apk/debug/app-debug.apk`

## Notes
- Requires Android SDK 35 and Java 17.
- Requires an internet connection.
- Uses JSONPlaceholder as a demo API. POST requests are simulated and are not permanently stored.
- Gitpod can build the APK, but a separate Android device or emulator is needed to run the APK.
